Key decisions:
- `EventDateTime` is floating local time (no TZID): the picker captures wall-clock
  time, and there is no time-zone DB in the app.
- ICS/Google formats are formatted with integer arithmetic, **not** `DateFormat`,
  so they never depend on intl locale data being loaded. Human-readable card text
  still uses intl, with a plain-English fallback if symbols are missing.
- Favourites/recents live in shared preferences (person-level), merged rather than
  replaced on load so an early tap is not lost; `studio.catalogLoaded` exposes the
  load future for tests.
- Changing the celebration swaps a bundled tune but never touches imported music.
- Duplicate = fork with a new ID (document ID follows) and opens the copy.

Gotchas found while testing:
- `SwitchListTile` inside a coloured Container asserts in debug builds
  ("ListTile background color … may be invisible") → replaced with Row + Switch
  wrapped in MergeSemantics.
- In `testWidgets`, `studio.flush()` never completes (its `Future.delayed` needs
  the fake clock) — drive the queue with `pumpAndSettle` instead.
- Widget tests must cancel the 650 ms autosave debounce (`await studio.saveNow()`)
  before the test ends or `!timersPending` fails.
